# 练一下 · 手机摄影（Practice AI）

AI 实践型手机摄影教练。核心体验不是“AI 讲摄影”，而是：

> 现实拍摄任务 → 上传照片 → AI 按本关 Rubric 检查 → 只给一个可执行动作 → 重拍 → Before / After 验证 → 更新技能状态。

## 当前阶段

项目按阶段开发，当前目标为 **Phase 1 — Mock Killer Loop**：

```text
Practice
→ Capture
→ Mock Retry
→ Capture
→ Before / After Compare
→ Complete
```

Phase 1 明确不接后端、不接真实 AI、不接数据库、不接 LangGraph。

详细计划见后续 `docs/development-plan.md`。
