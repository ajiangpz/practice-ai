## Task

Create the Taro 4 + React + TypeScript + Sass mini-program frontend and implement:

```text
Practice
→ Capture #1
→ Mock Retry
→ Capture #2
→ Before / After Compare
→ Complete
```

## Required behavior

- `/pages/practice/index`
- `/pages/capture/index`
- `/pages/coach/index`
- `Taro.chooseMedia()` with camera + album
- preview and reselect/retake
- first attempt persists the Before image
- first attempt renders the specified mock Retry result
- Retry CTA starts attempt 2
- second attempt persists the After image
- second attempt renders real Before/After images
- completion state is explicit
- core state persists via Taro Storage
- domain state is represented with TypeScript types
